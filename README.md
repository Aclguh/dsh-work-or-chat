# 工作 / 对话 (Work / Chat)

在 DeepSeek Harness 侧边栏加入「对话 / 工作」切换：

- **工作**：保持 Harness 原样。
- **对话**：直接运行官方 [chat-demo](https://github.com/deepseek-ai/chat-demo)（MIT）构建产物，界面、图标、设置、消息操作、历史菜单、语音与附件全部使用 demo 自己的实现。

## 功能

- 「新会话」行右侧 / 对话页「开启新对话」按钮右侧的胶囊切换。对话页按宿主侧边栏宽度渲染；切换按钮位置与工作模式完全一致，New chat 按钮自动缩短，避免和切换键重合。
- 官方 chat-demo 的完整界面：品牌行、开启新对话、历史分组、设置、欢迎页、输入框、深度思考/智能搜索、语音输入、上传文件、发送。
- 侧边栏顶部使用官方鲸鱼 wordmark（鲸鱼 + `deepseek` logo 字体），保留 demo 的收起按钮。
- 中央欢迎页显示官方鲸鱼图标和「你好，让我们开始聊天吧」启动问候。
- 消息操作：复制、朗读、重新生成、消息分支；用户消息可编辑；AI 回复底部显示搜索来源卡片与正文引用角标。
- 历史会话右侧三点菜单：重命名、删除；删除有二次确认。
- 设置：主题（浅色/深色/跟随系统）、语言、朗读音色、位置信息、数据管理。
- 数据管理：导入/导出 DeepSeek `export_format_version: 3` 的 `deepseek_data-*.zip`；导入会覆盖本地历史（官方 demo 行为）。
- 深度思考、智能搜索、链接阅读、Markdown、代码高亮、KaTeX、Mermaid。
- 对话通过 Host 代理使用 DSH 登录的 DeepSeek 账号；浏览器不会拿到账号 token 或 API Key。

## 实现方式

对话模式是一个本地 iframe，加载插件内置的 chat-demo 构建产物：

- 静态资源与 `/api` 代理由 Host 在 `127.0.0.1` 上启动的本地服务提供。
- 消息请求使用 DSH 账号；ASR/TTS 使用插件保存的 API Key 或 `DEEPSEEK_API_KEY`。
- 每次启动生成随机 token，iframe 的 `/api` 请求必须携带，避免其他 localhost 页面复用代理。
- 历史、草稿、设置保存在 demo 自己的 IndexedDB 中，origin 为本地服务地址。
- 关闭插件会停止本地服务；历史仍保留在浏览器 IndexedDB 中。

## 安装

1. 打开 DSH Web GUI → **插件** → **添加插件** → 选择本地目录：

   ```
   <path-to-dsh-work-or-chat>
   ```

2. 启用「工作 / 对话」。
3. 刷新页面。侧边栏「新会话」行右侧出现切换；展开侧边栏后可用。

## 使用

- 点「工作」回到 Harness；点「对话」进入对话模式。
- 第一次进入对话模式时，API Key 一栏显示「由 DSH 登录自动提供」；不需要再填 Key 即可聊天。
- 对话框的「语音输入」需要麦克风权限；「朗读」使用 API Key 的 TTS 接口。若环境里没有可用的 API Key，语音/朗读会提示失败，文字对话不受影响。
- 历史会话悬停或选中时右侧显示三点菜单，可重命名或删除。
- 设置 → 数据管理可导入/导出/删除全部历史。

## 导入

- 支持 `chat.deepseek.com` 导出的 `deepseek_data-*.zip`（v3）。
- 导入会**替换**当前本地全部会话与附件，这是 chat-demo 的官方行为；请先导出备份。
- 导入不需要 API Key，纯本地解析。

## 凭证

- 文字对话：优先使用已登录的 DSH DeepSeek 账号；Host 代理负责鉴权。
- 朗读/语音：ASR/TTS 接口要求 API Key，Host 依次使用插件保存的 Key、`DEEPSEEK_API_KEY`。DSH 账号 token 不能用于这两个接口。
- 所有密钥只留在 Host，浏览器和 iframe 只拿到本地代理地址和一次性 token。

## 数据与限制

- 对话历史在 demo 的 IndexedDB 中，origin 固定为 `http://127.0.0.1:24210`。端口被占用时会在同一端口重试，不会改用新端口，避免 origin 变化导致“历史消失”；重试 30 秒仍失败会显示启动失败。
- 更新插件不会删除 IndexedDB 中的历史；升级前仍建议在「设置 → 数据管理」导出 ZIP 作为备份。
- 若当前运行在临时端口（如 24211）且其中有新会话，请先在该页面导出，再重启到固定 24210；旧 24210 数据会恢复。
- 不连接、不同步 `chat.deepseek.com` 或 App；导入只是本地副本。
- 模型为 chat-demo 默认的 `deepseek-flash`；demo 本身不提供模型切换。
- 语音/附件依赖麦克风权限和 API Key；某些环境下浏览器会拦截自动播放或麦克风。
- 对话模式没有 Harness 工具、文件或工作区上下文。

## 验证

已验证环境：DeepSeek Harness `0.2.2-rc.3`，Windows 桌面版 / Web GUI。

- 工作 / 对话切换：280px 与 336px 侧边栏下，切换按钮与工作模式坐标一致；New chat 按钮缩短后无重叠。
- 对话：流式回复、停止、重新生成、复制、编辑、消息分支。
- 智能搜索：回复底部显示「已阅读 N 个网页」与来源卡片、正文引用角标。
- 朗读：TTS 代理返回 `audio/pcm; rate=24000`；语音输入复用同一 API Key。
- 历史：三点菜单重命名/删除；导入官方 v3 ZIP 后显示「已导入 1 个对话」。
- 设置：主题/语言/朗读音色/位置/数据管理；API Key 显示由 DSH 登录提供。
- 设置、导入确认、删除确认等弹窗打开时，切换键会随遮罩一起变暗并暂时禁用；关闭后恢复。
- 固定端口：重启后仍使用 24210，历史正常恢复。
- 侧边栏收起/展开时，切换键会跟随 demo 的折叠状态移动到左上角；展开后回到宿主位置。
